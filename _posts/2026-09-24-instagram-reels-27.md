## Info
> Our Instagram account had 27 posts and not a single video. The gameplay clips we had already recorded for YouTube Shorts were sitting unused, so we re-cut all of them into Reels. This post covers the three things that mattered: 1.5x speed, keeping the original 9:16 frame, and the fact that links in an Instagram caption are not clickable.

## 동영상이 한 편도 없었다

계정을 열어 보니 게시물 27개가 전부 이미지 캐러셀이었습니다. 앱 소개 카드 세 장씩 묶어 올린 것들입니다. 릴스는 0편이었습니다.

그런데 유튜브 쇼츠에 올리려고 찍어 둔 게임플레이 영상은 이미 25편이 있었습니다. 새로 만들 것이 아니라 **형식만 바꾸면 되는 재고**였습니다.

## 1. 1.5배속

원본은 35~47초입니다. 쇼츠에서는 괜찮은 길이인데, 릴스에서 30초가 넘는 무음 플레이 영상은 깁니다. 손가락이 먼저 움직입니다.

1.5배속으로 줄이니 23~31초가 됐습니다. 같은 내용인데 체감이 다릅니다.

```bash
ffmpeg -i gameplay.mp4 \
  -filter:v "setpts=PTS/1.5" -an \
  -c:v libx264 -preset medium -crf 23 \
  -pix_fmt yuv420p -movflags +faststart \
  reels/snake.mp4
```

`-an`으로 오디오를 버립니다. 게임 녹화에 소리가 없거나 의미가 없고, 릴스는 어차피 보는 쪽에서 음악을 얹습니다. 인스타 편집 화면에도 "소리가 없는 동영상"이라고 안내가 뜹니다.

## 2. 9:16을 지키는 것이 기본값이 아니다

여기서 한 번 틀렸습니다.

영상을 올리면 자르기 화면이 나오는데 **기본 비율이 1:1**입니다. 그대로 다음으로 넘기면 1080×1920 세로 영상의 위아래가 잘려 나갑니다. 게임 화면의 점수판이나 버튼이 사라지는 자리입니다.

자르기 화면에서 비율 선택 아이콘을 눌러 **'원본'**을 골라야 합니다. 그러면 미리보기가 0.56(=9:16) 비율로 돌아옵니다. 저는 한 편을 그냥 넘겼다가 편집 단계에서 되돌아가 고쳤습니다.

## 3. 영상 출처가 한 곳이 아니었다

25편은 `store-assets/<앱>/gameplay.mp4` 규칙을 따르고 있었습니다. 그래서 파일 목록을 훑고 "파티 앱 두 종은 영상이 없다"고 판단했는데, 틀렸습니다.

그 둘은 규칙이 생기기 전에 만든 앱이라 **iOS 시뮬레이터 녹화본**이 완전히 다른 폴더에 있었습니다. 규칙이 생기기 전의 자산은 규칙으로 찾을 수 없습니다.

찾고 보니 1206×2622였습니다. 9:16보다 세로로 길고, 위에는 iOS 상태바가, 아래에는 빈 공간이 있었습니다. 상태바를 잘라내면서 9:16으로 맞췄습니다.

```bash
ffmpeg -i preview.mp4 \
  -filter:v "crop=1206:2144:0:180,setpts=PTS/1.5,scale=1080:1920" -an \
  -c:v libx264 -crf 23 -pix_fmt yuv420p -movflags +faststart \
  reels/spin-the-bottle.mp4
```

`crop=1206:2144:0:180`은 위에서 180px(상태바), 아래에서 298px(빈 공간)을 잘라 9:16을 만드는 값입니다. 90MB짜리 원본이 5MB로 줄어드는 건 덤이었습니다.

## 4. 캡션의 링크는 눌리지 않는다

캡션 끝에 스토어 주소를 세 줄 넣었습니다.

```
Google Play: https://play.google.com/store/apps/details?id=com.fadongkwon.snake
토스 미니앱 / Toss: https://fadongkwon.com/toss/snake/
홈페이지 / Homepage: https://fadongkwon.com
```

알아 두실 것은 **인스타그램 캡션의 URL은 링크가 되지 않는다**는 점입니다. 클릭되는 건 프로필의 링크 한 줄뿐입니다. 그래도 넣은 이유는 두 가지입니다. 어디서 받을 수 있는 앱인지 글로 알리는 것, 그리고 주소를 보고 직접 칠 수 있게 하는 것.

토스만 우리 사이트를 거치는 데에도 이유가 있습니다. **토스 미니앱에는 공개 웹 주소가 없습니다.** 앱 안에서만 열립니다. 그래서 `fadongkwon.com/toss/<앱>` 랜딩을 하나 두고, 폰에서 열면 토스로 넘기고 PC에서 열면 안내를 보여주게 해 뒀습니다.

## 남은 문제

원래는 기존 이미지 게시물 27개의 캡션에도 같은 링크를 넣으려 했습니다. 그런데 **캡션 수정이 반영되지 않습니다.** 수정 요청은 `200 OK`를 받는데 캡션은 그대로입니다. 40자만 덧붙이는 최소 수정도 마찬가지였습니다.

같은 계정, 같은 시간에 새 게시물은 27건이 연달아 정상으로 올라갔습니다. 그러니 계정이 막힌 것이 아니라 **편집 동작에만 걸린 제한**입니다. 링크 보강은 릴스 쪽으로 돌렸고, 기존 게시물은 제한이 풀리면 손보려고 합니다.

## 정리

- 이미 찍어 둔 영상이 있다면 형식만 바꿔도 채널 하나가 열립니다
- 1.5배속은 내용을 해치지 않으면서 릴스 호흡에 맞춥니다
- 세로 영상은 **자르기에서 '원본'을 직접 골라야** 안 잘립니다
- 규칙이 생기기 전의 자산은 규칙으로 찾을 수 없습니다
- 인스타 캡션의 링크는 눌리지 않습니다. 그래도 적어 두는 편이 낫습니다
